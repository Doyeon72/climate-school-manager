# 우리 학교 기후환경 매니저 MVP v5

상현중학교 적용 데모용 PWA입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## v5 반영 사항

- 상단 문구를 `카카오 테크포임팩트리빙랩 단국대학교 기후보호대`로 변경
- 적용 학교를 `상현중학교`로 표시
- 상현중학교 에너지 카드 데이터를 `1.32 kgCO₂-eq/m²`로 변경
- 조아용 이미지가 잘리지 않도록 `object-fit: contain` 방식으로 수정
- 조아용 테마명을 `공원 조아용`, `재활용 조아용`, `탄소중립 조아용`으로 변경
- 알림 노란 박스는 다른 화면이나 빈 공간을 클릭하면 사라지도록 수정
- 1단계 관찰 기록의 상세 내용, 2단계 개선 제안의 모든 서술형 항목을 작성해야 등록되도록 수정

## 조아용 이미지 교체 방법

`public` 폴더에 아래 파일명으로 이미지를 넣으면 앱에서 자동으로 사용합니다.

- `joayong-basic.png`: 기본 조아용
- `joayong-park.png`: 공원 조아용, 20pt 보상
- `joayong-recycle.png`: 재활용 조아용, 40pt 보상
- `joayong-carbon.png`: 탄소중립 조아용, 60pt 보상

현재 v5에는 사용자가 제공한 공원 조아용 이미지를 예시 파일로 넣어두었습니다. 재활용 조아용과 탄소중립 조아용 파일을 확보하면 위 파일명으로 교체하면 됩니다.

## 사용 주의

조아용 이미지는 용인시 공공저작물 이용 조건을 확인한 뒤 사용해야 합니다. 비영리 목적, 출처 표시, 상업적 이용 금지, 변경 이용 금지 조건을 지키는 방식이 안전합니다.


## v5 수정 사항
- 조아용 테마별 PNG 파일 4개를 public 폴더에 반영했습니다.
- 톱니바퀴 버튼 클릭이 안정적으로 작동하도록 이벤트와 z-index를 보완했습니다.
- 에너지 카드 설명을 중학생 눈높이 문구로 수정했습니다.
- 태블릿 화면에서 상단 카드가 더 안정적으로 보이도록 반응형 CSS를 보완했습니다.
